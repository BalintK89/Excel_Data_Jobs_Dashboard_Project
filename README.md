# 📊 Data Jobs Analysis & Salary Dashboard

An interactive Excel dashboard analyzing global Data Analyst job postings, salaries, top-demanded skills, and employment types. 

This project was built following the **Data Analyst Bootcamp** by *Luke Barousse*, demonstrating end-to-end data processing, transformation, and visualization in Microsoft Excel.

---

## 🛠️ Key Tools & Features Used
- **Power Query:** Data cleaning, type transformations, missing value handling, and custom column creations.
- **Pivot Tables & Pivot Charts:** Aggregating data across multiple dimensions (salaries, skills, locations).
- **Advanced Formulas:** `XLOOKUP`, `INDEX/MATCH`, `SUMIFS`, `AVERAGEIFS`, and conditionally formatted metrics.
- **Interactive Dashboard:** Dynamic filtering using **Slicers** and customized charts for seamless exploration.

---

## 📈 Key Insights & Business Findings
- **High-Demand Skills:** SQL and Python consistently rank as the top required skills for Data Analyst roles.
- **Salary Benchmarks:** Median salaries vary significantly by location and work schedule (Remote vs. On-site).
- **Skill Premium:** Advanced tools (like Cloud platforms and specialized BI tools) correlate with higher median compensation packages.
